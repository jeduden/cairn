# 5. Functional requirements: owner acts and peers

The owner-act and peer families of §5, kept in their own file. Each
table lists: **ID** · **Pri** · **Requirement** · **Ver**
(verification method) · **Traces** (invariants).

## 5.13 Owner acts (OWN)

OWN holds every act by which a person reaches an agent: answers,
steering, endorsement, rule levels, the classes of owner acts, and the
sandbox state they rest on. Each row touches I2, and the security
reviewer reviews them as one block.

## 5.14 Peer network (PEER)

specified now, built after the standalone release and its security
review.
