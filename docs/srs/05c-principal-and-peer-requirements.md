# 5. Functional requirements: principal acts and peers

Each table lists: **ID** · **Pri** · **Requirement** · **Ver**
(verification method) · **Traces** (invariants).

## 5.13 Principal acts (OWN)

The OWN family covers principal acts, among them every act by which a
principal reaches an agent. An act a seat key
signs is a room act wherever it is taken, never a principal act
(LANE-31). Each row touches I2, and the security reviewer reviews them
as one block.
