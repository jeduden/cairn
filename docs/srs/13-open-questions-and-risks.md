# 13. Open questions and risks

## 13.1 Open questions

| ID    | Question                                                                                                                                                                                                                                                                                                                                                          | Owner / resolution path                                                                                                                                                           |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OQ-01 | Should Cairn control compaction? Options: (a) coexist with native compaction (v1 default); (b) defer compaction via `PreCompact` and manage eviction itself; (c) an API proxy that keeps prompts small (CliffCompaction-style). A proxy is a network component and would conflict with I4, so it could only ship as a separate, independently reviewed component. | S6                                                                                                                                                                                |
| OQ-02 | Does `PreCompact` output reliably influence the compaction summary, including for subagents?                                                                                                                                                                                                                                                                      | S1                                                                                                                                                                                |
| OQ-03 | Is pure-Go SQLite fast enough at 10M events, or is a CGO build needed for large deployments (which would break CON-02 for that build)?                                                                                                                                                                                                                            | Answered by S2: no CGO build. Its 1.5–2× would close none of the 10M-event misses (full BM25 ranking of common terms, one event per commit, store overhead), so M1 bounds ranking |
| OQ-04 | Encryption at rest: encrypting SQLite VFS, application-level AEAD for payloads, or encrypted volumes only; and key management on ephemeral runners.                                                                                                                                                                                                               | S2: an encrypting VFS is feasible as an opt-in with ncruces (`xts`, `adiantum`); the default and key management stay with the security review                                     |
| OQ-05 | Redaction makes the record intentionally lossy for secrets. Is an optional, separately encrypted raw vault needed for forensics?                                                                                                                                                                                                                                  | Security team                                                                                                                                                                     |
| OQ-06 | Can `interactive` mode be detected reliably, or must it always be declared by configuration?                                                                                                                                                                                                                                                                      | S4                                                                                                                                                                                |
| OQ-07 | Design for shared stores across hosts: per-tenant row security, provenance-gated sharing, blast-radius limits.                                                                                                                                                                                                                                                    | Post-v1 proposal                                                                                                                                                                  |
| OQ-08 | Should Cairn offer an in-process integration for Agent SDK callbacks in addition to command hooks?                                                                                                                                                                                                                                                                | Post-M2                                                                                                                                                                           |
| OQ-09 | Project license: Apache-2.0 proposed for its patent grant.                                                                                                                                                                                                                                                                                                        | Product owner                                                                                                                                                                     |
| OQ-10 | Starlark or Python as the default kernel language.                                                                                                                                                                                                                                                                                                                | S5                                                                                                                                                                                |
| OQ-11 | Should recall-log events (RCL-07) be excluded from `search` by default to avoid recall results echoing earlier queries?                                                                                                                                                                                                                                           | M1                                                                                                                                                                                |

## 13.2 Risks

| Risk                                             | Likelihood | Impact | Mitigation                                                                                      |
| ------------------------------------------------ | ---------- | ------ | ----------------------------------------------------------------------------------------------- |
| Claude Code changes hook or transcript contracts | High       | High   | Adapter isolation (ADR-08), contract tests per version (ENG-17), loud format detection (NFR-11) |
| Claude under-uses recall tools                   | Medium     | High   | Recall statement in restore block, tuned tool descriptions, tool-use metric (§11.1)             |
| Structural landmarks too coarse to navigate      | Medium     | Medium | Ablation C−L; trusted-only LLM headlines (LMK-06)                                               |
| Starlark too limiting for Claude                 | Medium     | Medium | Spike S5; optional Python kernel (CMP-08)                                                       |
| Pure-Go SQLite performance insufficient          | Low        | High   | Spike S2; driver choice; CGO build as documented exception                                      |
| Lossless record retains poisoned content         | High       | Medium | Quarantine (SEC-12), flagging (PRV-07), retention (REC-15), pull-only recall (INJ-03)           |
| Flagging heuristics give false confidence        | Medium     | Medium | Flags are advisory; the controls are I2 and envelopes; precision tracked                        |
| Security defaults reduce adoption                | Medium     | Medium | Zero-config defaults that work well; convenience opt-in, not absent                             |
| Multi-session reasoning stays weak               | High       | Low    | Kernel aggregation; tracked metric; not claimed as solved                                       |
| Maintainer concentration                         | Medium     | High   | ENG-21, ENG-25                                                                                  |
